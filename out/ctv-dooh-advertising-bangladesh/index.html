HOW IT WORKS

A screen is not live until the integration can prove playback.

Each stage should have a clear owner, valid inputs and an auditable output.

01

Link the adapter

Connect the CMS/player with the required network token, API credential or device mapping.

02

Describe the screen

Provide screen ID, venue, latitude/longitude, resolution, aspect ratio, orientation and operating hours.

03

Create the programmatic slot

Insert the supported ad-source/programmatic placeholder and configure duration, fallback and creative rules.

04

Cache, play & report

Prefetch where supported, validate playback and reconcile proof-of-play before calling the screen live.

DOOH INTEGRATION

A separate adapter layer connects the screen to programmatic demand.

Digital signage playback alone is not enough. The player or CMS needs a compatible integration path that can identify the screen, request an eligible ad, cache and play the creative, and return playback evidence.

01

Adapter identity

Map account/network credentials plus device, player or screen identifiers required by the integration.

02

Venue metadata

Provide latitude/longitude, venue type, resolution, aspect ratio, orientation, operating hours and supported media.

03

Programmatic slot

Configure the ad-source placeholder, creative rules, duration, fallback behavior and category controls.

04

Playback verification

Use test mode where supported, inspect player logs, verify the physical screen and reconcile proof-of-play.

COMMON QUESTIONS

Clear answers before you activate.

These answers are written for people first and are aligned with the availability and verification rules used across Boost RAVA.

Does a digital signage screen automatically support programmatic DOOH?+

No. A screen typically needs a compatible CMS/player integration or adapter plus inventory metadata, request handling, creative playback and proof-of-play reporting.

Where can Boost RAVA plan DOOH in Bangladesh?+

The page is designed for eligible station, transit, market, retail, airport and high-footfall environments where inventory has been onboarded, verified and approved.

Is CTV the same integration as DOOH?+

No. CTV is a buyer-side video inventory path, while DOOH requires screen/player onboarding and venue-level integration. Availability is supply-dependent.

READY TO MOVE?

Plan the campaign—or onboard the screen correctly first.

CTV and DOOH can sit in one media plan, but they should keep separate inventory, integration and measurement logic.
